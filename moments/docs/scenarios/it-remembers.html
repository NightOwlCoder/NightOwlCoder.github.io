The story

Every chat tool forgets you when the window closes. The workaround is a person re-explaining their own decisions, or a rules file that grows until nobody reads it. The cure is memory that is written by the system from what happened, and that shows its source when it speaks.

April · surfaced unasked, with the reason and the source · one question instead of a wrong build

Three properties make the moment. It was never told to remember: the system wrote the fact from the turn. It spoke before the mistake, not after. And it showed where the fact came from, so the person can check it rather than trust it. The link goes to the March conversation, not to "my memory says".

How it is sold

The four parts of this teaser

PartThis scenarioWhy

one beat of proof Six weeks, a different project, and it says "you decided against that in March" with the reason and a link. Distance in time and distance in topic are the two things a context window cannot bridge. Naming both is the proof. The link is what makes it checkable rather than a claim.
who does it 🗿 Draal · memory and context Memory has an owner. His charter is recall, compaction, consolidation, and "was this already done before redoing it".
the way out see all 12 → Always visible.

Rejected wording: "long-term memory", "knowledge graph", "learns your preferences". The first two are architecture; the third is a promise about behaviour the person cannot check. The copy says what happened: it spoke first, gave the reason, and linked the source.

What keeps it honest

The three layers exist and run: on this machine, in the last 24 hours, the brain fired 648 recalls and surfaced 2,761 connections, of which 469 were cited by the receiving turn and 1,961 were acted on. The world-knowledge store holds 1,709 entities and 179 compiled truths; 37,349 turn summaries are indexed. What the copy must not imply: that memory is a transcript. It is a store of attempts: a past turn's "decided" means a past agent said so, and the compiled truth carries a flag when its own guards doubt it. "You can check it" is the honest promise; "it is right" is not. The story's link is the check.

part three

How it is built

Measured on main and on this machine's stores. The recall, the write path and the source link all exist. The gap is the shape of the sentence: today the surfaced fact arrives as a block for the model to use, not as a line the person reads.

drawn against: brain/pulso.rs · brain/outcome.rs · memory/store.rs · memory/compile_truth.rs · memory/nudge.rs · SPEC_MEMORY_V2.md · SPEC_BRAIN_V0.md (superseded note) · k brain_status · sqlite3 on the three stores

Three layers, three write paths

LayerWhat it holdsWritten byOn this machine
brain Every turn's summary as a 768-dim vector; on every turn completion, top-5 cosine recall across all other sessions; a match is buffered and delivered to the receiving session's next message as <brain-context>. Each delivery is tracked: cited? acted on? — three-valued, never "no" by default. the engine, per turn (run_pulso) 37,349 summaries · 648 pulsos/24h · p50 116 ms
world knowledge People, projects, decisions, tools: entities with observations and a compiled truth that is rewritten only when observations at least double, under four guards (empty, length_regression, length_inflation, contradiction). A flagged rewrite persists with its reason and renders a ⚠️. nightly consolidation + per-turn nudge (conf ≥ 9 to create an entity) 1,709 entities · 7,439 observations · 179 truths
operational How to work in a project: tool quirks, conventions. Rendered into a 4 KB frozen snapshot at session start, ranked by confidence then recency; never re-queried mid-session. background nudge (challenger-filtered) + k learn_add 645 rows

What does not exist yet

GapWhat it takes
The fact as a line the person reads Today the recall is input to the model; whether it becomes a sentence depends on the model following Layer 0. The story's "in March you decided…" is a rendered brain-context block: same identifier-ban rule as scenario 01, source label as the link, never the raw block. An event the clients render, so the model cannot skip it.
Cross-project recall for a stranger Works here because every project's sessions live in one sessions.db. Holds for a fresh install by construction; nothing to build, but the copy's "different project" claim should be tested on a fresh box before it ships.
"Here's why" A brain match carries goal/action/status; the reason for a decision is in the L1 observation, if the nudge captured it. The story assumes the reason was written. Honest copy: "here's what you said" — the reason if it was said.

Rejected, with reasons

ShapeWhy not
"Remember this" as a command the person must issue The person forgets to say it exactly when it matters. The write path is automatic; learn_add exists for the rare explicit case.
Paste the whole past conversation into context Layer 0 forbids it: a summary and a label, one to two sentences, never the block. The person sees a sentence and a link.
Trust the memory It is a memory of attempts. The compiled truth carries auto_flagged and flag_reason for a reason. The link is the check; the copy sells the check.
A rules file the person maintains That is what the operational layer replaces: written by the system, ranked by confidence, capped at 4 KB so it is actually read.
